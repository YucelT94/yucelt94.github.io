# yucelt.dev

Personal landing page, served by GitHub Pages from `master` (custom domain in `CNAME`).

- `/` — landing page (`index.html`, `assets/`), based on [Aerial by HTML5 UP](https://html5up.net) (CCA 3.0, see `LICENSE.txt`)
- `/vienna-trip` — Vienna New Year's trip guide (`vienna-trip/index.html`, self-contained)
- `/endulus-trip` — Andalusia road trip guide (`endulus-trip/index.html`, self-contained)

No build step: edit the files and push.
